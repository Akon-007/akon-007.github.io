Metastractor

Pull the hidden story out of a photo — down to the device and the coordinates.

Python Digital Forensics Streamlit

Overview

Metastractor is an advanced metadata extraction utility engineered to parse, analyze, and strip hidden EXIF and document properties from various file formats.

Built for intelligence gathering and privacy hardening, it automates the discovery of sensitive underlying metadata such as author credentials, timestamps, and geolocation tags.

The tool highlights the security risks associated with unstripped file metadata, providing a streamlined mechanism for forensic analysis and personal privacy protection.

What it does

Creation metadata

Recovers timestamps and details about when a file was produced.

Hardware identification

Reveals the device or camera that captured the image or video.

Location extraction

Pulls embedded coordinates where the source file recorded them.

Interactive interface

Explores results through a Streamlit app rather than raw output.
